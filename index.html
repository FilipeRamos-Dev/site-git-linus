Tutorial de como versionar em Git...

Iniciar um repositório:

Para iniciar um repositório Git é preciso acessar o software do Git pelo diretório onde você quer trabalhar no projeto e executá-lo com o comando 'git init'.

Verificar as modificações:

Depois de ter iniciado o repositório vamos conferir as alterações a serem "commitadas", para que isso seja possível precisamos executar o comando 'git status'.

Preparar para o commit:

Depois de verificarmos os status das modificações, precisamos preparar elas para o commit, para que isto seja possível é preciso executar o comando 'git commit -m "Descrição das alterações"'.
OBS: É aconselhável usar o '-m' na frente do commit para infomarmos as alterações feitas no projeto.

Conectar ao repositório:

Posterior ao commit, precisamos conectar aquele commit no Git ao repositório GitHub utilizando o comando 'git remote add origin linkRepositorio/github.com'.
OBS: Podemos verificar se o repositório Git Hub está vinculado utilizando o comando 'git remote -v' - O '-v' faz referência a "view" de visualização.

Empurrar para o repositório:

Por fim podemos colocar, finalmente, as alterações ao repositório do GitHub executando 'git push origin main' - 'main' faz referência a identificação do repositório -.
OBS: Quando estiver trabalhando em equipe utilize o 'git pull ...' no lugar de 'git push ...' para que as alterações sejam levadas ao servidor permitindo que os outros usuários participantes visualizem.

Fluxo de comandos...

  • git init
  • git status
  • git add
  • git remote add origin
  • git push origin main
